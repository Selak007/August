August Privacy Policy
Version 1.1 · Updated October 2026 · Open Source MIT
🔒 100% On-Device · Zero Remote Audio · Single-Purpose Browser Control

August is designed from the ground up with a privacy-first, local-first architecture. We believe that your browser navigation, voice recordings, and browsing activity are strictly your own personal business.

1. Core Privacy Commitments

  • Zero Remote Data Collection: We do not operate user accounts, cloud databases, telemetry endpoints, or analytics servers.
  • Local Speech Recognition: By default, speech is transcribed inside your browser using Whisper WebAssembly running directly on your CPU. No audio leaves your machine.
  • No Ads or Third-Party Trackers: The extension contains no ad networks, cookies, or monetization trackers.
  • Single-Purpose Design: Built exclusively to allow voice-activated browser navigation and control.

2. Audio and Voice Data Handling

A. In-Browser Whisper (Default & Recommended)

When you press the microphone button or hands-free listening is active, audio is sampled into a temporary memory buffer in your browser (16 kHz mono Float32Array). A dedicated Web Worker processes this buffer using OpenAI's Whisper model (quantized Xenova/whisper-tiny.en) compiled to WebAssembly. The audio buffer is cleared immediately once transcribed.

Audio data is never transmitted over the internet or saved to persistent storage.

B. Chrome Web Speech (Optional Fallback)

If you explicitly select "Chrome Web Speech" in Settings, your browser uses Google's native speech recognition API. In this mode, audio is sent to Google's speech recognition cloud servers under Google's Privacy Policy.

C. Local Python Backend (Optional Developer Mode)

If enabled, communication with the local desktop daemon occurs solely over local loopback (127.0.0.1) using a shared token. No external network traffic is created.

3. Chrome Permissions Rationale

Permission Strictly Defined Purpose
tabs & activeTab To navigate, switch, close, pin, mute, zoom, and manage tabs when instructed by voice (e.g. "open youtube", "close tab").
scripting To execute page interactions such as scrolling up/down or clicking numbered elements as requested.
sidePanel To display the voice assistant interface next to your active webpage without interrupting navigation.
storage To save your preferences (TTS voice, speech speed, STT engine) locally on your device.
tts To provide optional spoken confirmations using your browser's built-in speech synthesizer.
windows & sessions To support commands like "open new window" and "reopen closed tab".
Host permissions (<all_urls>) Allows voice scrolling and interaction on any website you are currently browsing.

4. Data Retention and Control

Recent command history is kept in memory and local storage solely to display activity in the side panel. You can permanently wipe this history at any time with one click via Settings → Clear history.
